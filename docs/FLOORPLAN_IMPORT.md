# 도면 사진으로 시작하기

`시작 → 우리 집 도면 올리기`에서 PNG, JPG, WebP 이미지를 선택합니다. 파일은
20MB까지 받을 수 있으며, 시작 화면에 끌어놓거나 붙여넣어도 됩니다.
공간 패널의 `도면 따라 그리기 · 축척 → 이미지에서 공간 만들기`에서도 열 수 있습니다.

1. **공간 확인:** 원본 위의 윤곽과 번호를 확인합니다. 필요한 공간만 남기고 이름과
   종류를 바꿀 수 있습니다. `윤곽 수정`의 모서리를 끌거나 좌표를 입력해 보정합니다.
   거실 등 한 곳부터 시작하려면 `이 공간만 가져오기`를 누릅니다. 빠진 공간은
   `공간 추가`로 모서리를 찍어 완성합니다.
2. **크기 확인:** 표시된 기준선의 실제 길이와 단위를 입력합니다. 기준 벽을 바꾸거나
   두 점을 직접 지정할 수 있습니다. 사진에서 읽은 숫자는 후보이며, 해당 선의 길이인지
   직접 확인해야 합니다. 단위 없는 OCR 숫자는 단위를 선택하기 전까지 적용하지 않습니다.
3. **가구 배치:** `가구 배치 시작`은 기존 3D 편집기를 엽니다. `2D에서 더 고치기`는
   공간 편집기로 이어집니다. 확인한 기준 길이는 잠긴 치수선으로 남습니다.

문 후보는 벽의 틈에서 찾은 위치입니다. 창문이나 열린 경계일 수도 있으므로 실제 문인
곳만 선택합니다. 후보를 누르면 원본 위에 번호가 표시됩니다. 문 종류·방향·폭과
가구의 상세 편집은 3D에서 이어갑니다.

## 어떤 이미지가 잘 읽히나요?

- 선명하고 정면에서 본 인쇄 평면도나 캡처가 적합합니다. 설명 표나 여러 대안이 함께
  있으면 사용할 도면 부분만 잘라 올리는 편이 좋습니다.
- 기울어진 A4 촬영본은 `사진 보정 · 다시 인식 → 사진 원근 보정`에서 종이의 네
  모서리와 방향을 맞춥니다. 정면 캡처에서는 `기울기 없는 영역 자르기`를 선택합니다.
- 회전, 벽 선 진하기, 벽 틈 연결 정도를 바꿔 다시 인식할 수 있습니다. 다시 인식하면
  수정한 윤곽은 초기화됩니다.
- 수기 도면, 실내 사진, 흐린 선, 사선 벽의 큰 틈, 벽에 붙은 가구는 자동 추출이
  부정확하거나 실패할 수 있습니다. 닫힌 공간을 찾지 못했다고 임의의 방을 만들지는
  않습니다. 원본과 비교해 빠진 공간이나 잘못 연결된 모서리를 보정해야 합니다.
- 평형·면적만으로 실제 길이를 추정하지 않습니다. 자동으로 생성된 윤곽은 실측 결과가
  아니며, 가구 설치에 필요한 치수는 실제 공간과 확인해야 합니다.

## 데이터와 기존 작업

윤곽 추출과 숫자 읽기는 브라우저의 작업자에서 실행됩니다. 사진과 도면을 외부 인식
서비스로 전송하지 않습니다. 숫자 읽기용 Tesseract 작업자·모델은 앱과 같은 출처에서
필요할 때만 내려받습니다. 숫자 읽기가 실패하거나 아직 진행 중이어도 실제 길이를
직접 입력할 수 있습니다.

최종 적용 전에는 기존 프로젝트를 바꾸지 않습니다. 취소하면 이미지 처리 작업자도
종료합니다. 적용할 때는 기존 작업을 복구본으로 보호하고 새 로컬 프로젝트를 만듭니다.
기존 저장·실행 취소·도면 파일 내보내기 경계를 사용하며 전체 파일 제한은 1 MiB입니다.
외부 서비스의 임의 JSON, CAD, PDF 파일을 직접 해석하는 기능은 포함하지 않습니다.

시작 화면의 아파트 예시와 `전체 예시 찾기`는 현재 등록된 참고 도면만 검색합니다.
전국 단지 검색이나 실제 세대의 실측 도면을 제공하는 기능은 아닙니다.
