# 지역 아파트 참고 샘플

세 샘플은 공개 평면의 공간 배치와 출입 관계를 참고해 새로 만든 편집용 기하 데이터입니다. 실제 거주 세대나 특정 호수의 실측 도면이 아닙니다. 원본 이미지를 포함하거나 재배포하지 않습니다.

| 지역·단지 | 참고 평형 | 공개 출처 |
|---|---|---|
| 대치동 래미안대치팰리스 | 이미지 표기 전용 84.98㎡, 공급 112.24㎡; 세부 타입 문자 미확인 | https://medico.tistory.com/1578 |
| 압구정 현대 | 단지 35평형; 원도 전용 24.88평, 총 34.56평 | http://www.hyundaiapt.org/page/sub105 |
| 도곡동 도곡렉슬 | 33A, 전용 84.99㎡, 공급 111.08㎡ | http://www.rexleapt.com/html18/sub.html?sub=14 |

## 재구성 기준

- 현관에서 시작하며 침실은 공용 복도에서 직접 접근합니다. 부부 욕실은 안방 또는 드레스룸을 거쳐 접근합니다.
- 열린 거실·주방·복도는 같은 spaceId의 조각으로 연결합니다. 원본에 없는 문을 추가해 방을 억지로 연결하지 않습니다.
- 발코니·세탁실 등의 표시된 공간을 포함합니다. 정확히 판독되지 않는 개구부 폭, 창턱, 문 방향, 벽 두께와 가구는 추정입니다.
- 편집기 면적은 모델링한 직사각형 공간의 합집합이며 발코니를 포함합니다. 표기 전용·공급면적과 같지 않습니다.
- 공식 단지 자료와 공개 블로그의 이미지에 별도 재사용 허가가 확인된 것은 아닙니다. 기존 LH 데이터의 제한 없는 이용 조건을 이 자료에 적용하지 않습니다.

## 확인 경로

상단 시작 → 실제 아파트 참고 샘플은 대치동 샘플을 엽니다. 상단 모델 홈에서는 새 샘플 3개와 기존 LH 샘플 3개를 선택할 수 있습니다. 3D 미리보기 → 1인칭으로 전환해 둘러볼 수 있습니다.

## 검증

`node --test tests/regional-demo-layouts.test.js`는 기본 문 상태와 가구를 포함한 충돌 맵으로 모든 공간을 검사합니다.

`npm run build && npm run test:browser:regional`은 실제 Chrome의 문 표시·반응형·터치 통행을 검증합니다.
