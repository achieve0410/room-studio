# 서울 아파트 에셋 예시

Room Studio는 미리 제작한 3D 가구와 재질을 브라우저에서 조합합니다. 고객이 가구를
움직이거나 마감을 바꿀 때 AI 서비스를 호출하지 않습니다. 처음 모델을 열 때는 정적
에셋을 내려받으며, 도면은 기존처럼 현재 브라우저에 저장됩니다.

## 예시 열기

시작 화면의 지역 카드를 누르거나 **샘플 → 3D로 꾸며보기**를 선택합니다.

| 참고 평면 | 스타일 |
| --- | --- |
| 대치동 래미안대치팰리스 84.98㎡ | 오크와 린넨 |
| 압구정 현대 35평형 | 차분한 월넛 |
| 도곡렉슬 33A | 소프트 모던 |

기존 작업이 있으면 먼저 교체 여부를 확인합니다. 취소하면 작업을 그대로 유지합니다.
이 예시는 공개 평면을 참고한 재구성이며, 치수·가구 배치·마감은 추정과 제안입니다.
실제 세대의 인테리어나 판매 제품을 재현한 것이 아닙니다.
[평면 출처와 추정 범위](REGIONAL_SAMPLES.md)를 함께 확인하세요.

## 직접 꾸미기

- 장면의 가구를 클릭하거나 **대상 선택** 목록에서 고릅니다.
- 가구를 끌어 놓으면 한 번의 변경으로 저장합니다. 실행 취소로 이전 배치를 복원합니다.
- **가구 · 마감**에서 새 모델을 고른 뒤 미리보기를 끌어 놓거나, 수치를 조절하고
  **적용**합니다. **취소**는 미완료 변경만 되돌립니다.
- **선택 가구를 모델로 교체**를 켜면 기존 가구를 다른 모델로 바꿉니다.
- 회전·수치·재질은 미리보기 후 **적용**합니다. 가구의 주 마감, 공간의 바닥과 벽
  마감을 각각 선택할 수 있습니다.
- 빈 장면을 끌어 회전하고, Shift와 함께 끌어 화면을 이동하며, 휠로 확대합니다.
  터치에서는 두 손가락으로 확대·이동합니다.
- **전체 보기 / 위에서 / 걸어보기**로 배치와 통행을 확인합니다.
- **도구 더보기 → PNG 저장**으로 현재 장면을 저장합니다. 다른 브라우저에서 편집을
  이어갈 때는 2D 화면의 **파일**에서 도면을 내보냅니다.

3D에서 확정한 변경은 2D 편집기와 같은 저장·실행 취소 기록을 사용합니다. A/B안과
휴대용 파일에도 모델·재질 식별자를 보존하며, 오래된 도면에 새 모델을 자동 적용하지
않습니다. 모델 로딩이 실패하면 오류와 다시 불러오기 버튼을 표시합니다.

## 에셋과 구현 범위

원본 제작 GLB 가구 12종, 가구 마감 3종, 바닥·벽 재질 7종을 제공합니다. 특수 주방·욕실
설비는 기존 전용 모델을 유지합니다. 가구의 높이는 침대 헤드보드 등을 포함한 전체
높이입니다. 모델과 텍스처는 도면 JSON에 넣지 않고 정적 카탈로그에서 불러옵니다.
휴대용 파일의 1 MiB 제한은 그대로입니다.

이번 버전은 Pascal의 직접 편집 경험을 참고해 기존 Three.js 렌더러를 확장한 것입니다.
Pascal 패키지로 엔진을 교체하거나, Pascal의 계정·AI·협업 서비스를 연결한 버전은
아닙니다. 원본 에셋의 제작 방법, 치수, 용량, 라이선스는
[에셋 라이브러리 문서](asset-library.md)에 기록합니다.

## 재생성과 검사

```sh
npm ci --ignore-scripts
npm run assets:build
npm run assets:examples
npm run check
npm run test:browser:assets
npm run test:browser:regional
```

`assets:examples`는 격리된 실제 Chrome에서 세 예시를 열어 전체·상공 장면을 촬영합니다.
결과는 `public/assets/seoul-examples/`에 저장하며, manifest에 원본 도면과 이미지의
해시를 기록합니다. 카드에는 160·320·640 px WebP 미리보기를 화면 크기에 맞게 사용하고,
1128 px 원본은 유지합니다. 모델 대신 사진을 보여주는 기능이 아니라 실제 편집 장면의 표지입니다.
브라우저 검사는 동적으로 할당된 포트와 별도 프로필을 사용합니다.
